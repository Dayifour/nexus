# Démarrer ici

Nexus AI est une application desktop (Electron) qui orchestre des agents de code en CLI. Les CLI codent ; Nexus isole,
orchestre, relaie, relit et intègre.

1. Utilisateur : [`USER_GUIDE.md`](USER_GUIDE.md).
2. Contributeur ou agent de code : [`../CLAUDE.md`](../CLAUDE.md), puis [`ARCHITECTURE.md`](ARCHITECTURE.md), le
   [modèle de menace](threat-model/README.md) et les [ADR](adr/).
3. État réel : [`../.coordination/STATUS.md`](../.coordination/STATUS.md) ; décisions : [`../.coordination/DECISIONS.md`](../.coordination/DECISIONS.md).

Règles qui restent valables : aucune permission ajoutée, push ou déploiement sans validation explicite du propriétaire ;
une ambiguïté donne une question ou un ADR, pas une invention ; ne jamais lire un `.env` réel ni une clé privée ;
signaler ce qui est vérifié en réel et ce qui ne l'est que sur des faux.

Index complet : [`README.md`](README.md). Documents historiques : [`archive/`](archive/README.md).
